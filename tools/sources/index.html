Sources

Where every number on these pages comes from, and the check that runs each time a page loads.

How the tables are made

Saturation pressure for each refrigerant is computed from its reference equation of state, the same published equations NIST REFPROP uses, with CoolProp. Blends use the published mixture models for each pair of components (Lemmon and Jacobsen for the HFC pairs, Bell and co-authors for the pairs with HFOs and CO₂). That gives a bubble and a dew curve, one row per degree.

Then every table is checked against a table the manufacturer or NIST published. Where the two agree within the published rounding, the computed table stands. Where they don't, usually because the manufacturer used different mixture parameters, the table is matched to the published values at every printed point, and the equation of state is only used to fill in between them. The page says which, per refrigerant.

The check runs again in your browser every time this page loads: every published point is looked up through the same code the calculators use.

Charts printed in psig assume a 14.696 psia atmosphere, so the published psig values were converted to absolute on that basis. Not included yet: R-452B, R-454C, R-422D and R-438A. No published table turned up that they could be checked against, so they stay off the page until one does. No guessing.

These are numbers for clean, single refrigerant. Mixed or contaminated refrigerant and non-condensables read differently. Charge to the equipment manufacturer's instructions.
