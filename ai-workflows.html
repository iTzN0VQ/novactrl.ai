Claude skills for the field.

Open-sourced SKILL.md files I actually run on jobs. Each one solves a real callback or a real time sink.

What is a Claude skill? A SKILL.md file is a self-contained instruction set that teaches Claude how to perform a specific task — drive a desktop app, parse a form, run a checklist. Drop it into Claude Code or Cowork mode and it becomes a slash command.
TOOL · LIVE · OPEN SOURCE

Gauge Diagnostic

Enter suction and liquid line pressures plus suction and liquid line temps. The tool computes saturation temps, superheat, subcooling, compression ratio, and runs the NovaCTRL diagnostic ruleset for a verdict with field-tested causes and fixes. 16 refrigerants. No login, no install.

DSB Builder

Claude skill that builds Mitsubishi Diamond System Builder projects from a phone photo of a Field Survey Checklist. Validates the form, drives DSB on Windows via computer-use, handles R454B floor-area gates, M-NET defaults, per-zone controller routing — saves a .dsbx and exports a PDF submittal back to the contractor's phone. Saves 20–30 minutes per submittal.
