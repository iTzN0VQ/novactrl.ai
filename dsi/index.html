How it works

The form is the spec. The skill is built to follow it exactly and to stop when something is missing.

  1. 1

    Fill out the checklist and take a photo.

    Two pages, five sections: project info, the outdoor unit, the branch box, the output you want, and up to eight indoor units with their controllers. Snap it with your phone and drop it in the chat with build the DSB.

  2. 2

    The skill checks the form, then drives DSB.

    It checks the required fields for blanks and contradictions. When something is blank or unreadable, it’s designed to tell you what to fix instead of guessing.

    Then it opens Diamond System Builder on a Windows machine through Claude's computer-use and works through it the way you would: project properties, outdoor unit, branch box, every indoor unit, every controller. Along the way it fills in each room’s floor area for the R-454B check and sets M-NET defaults, branch box end caps and per-zone controller routing.

  3. 3

    A .dsbx and a PDF come back.

    The project is saved and the PDF submittal exported to the folder the form specifies. The PDF is attached back to the chat, so the contractor opens it on their phone.

    If DSB reports a design error, the skill is built to stop, name the conflict and wait for a corrected form. Design choices stay with the tech, and so does the final check of every submittal.

What it handles

Current-generation Mitsubishi residential and light commercial equipment, up to eight indoor units, with the controller logic that is easy to miss when a submittal is rushed.

Equipment
M-Series single zone, MXZ multi-zone, MXZ-SM Smart Multi and P-Series. Current-generation R-454B models.
Indoor units
Up to eight per project: zone, type, capacity, mount height, lineset, number of 90s, vertical rise or drop, floor area and controller for each.
Branch boxes
Three-port and five-port, with the run from the outdoor unit, the elbows and the elevation taken from the form. End caps set.
Controllers
PAR-42 wired, MHK2 wireless, kumo cloud, and PAC-445 with a third-party thermostat, routed per zone.
Validation
Required fields checked and contradictions flagged before DSB opens. Blank or unreadable fields come back as a list of what to fix.
Output
A saved .dsbx project and an exported PDF submittal in the folder the form names, with the PDF attached back to the chat.
Runs in
Claude, through the NovaCTRL connector. Coming soon.
Needs
A Windows machine with Diamond System Builder installed, and Claude with computer-use access to DSB and File Explorer.
Does not
Redesign systems, bypass M-NET, or handle City Multi. City Multi jobs use a different survey sheet.
Updates
From NovaCTRL only, as the skill keeps training.

Built run by run

Diamond System Intelligence isn't written once and shipped. It's trained every day, inside Diamond System Builder itself.

It began with Claude Opus 4.6, the first model we found that could take over a computer and work through Diamond System Builder on its own. Those first runs were slow and clumsy, but they finished, and that was enough to show what the skill could become.

So we gave it a way to keep improving. Every day, an agent on the latest Claude models works job after job in Diamond System Builder. Roadblocks and failures are studied and turned into what the skill knows the next time. It has also studied Mitsubishi's library of published manuals, the same rules the equipment is designed around.

That learning compounds. Each day starts from what the days before taught it, so the skill is built to get sharper the longer it trains. Catching up would take more than the idea. It would take the same daily investment, kept up for as long as we've kept it up.

What reaches you is the result: a skill shaped by the runs that came before yours. You still check its work, the way you would anyone’s. Video tutorials showing it at work are on the way.
