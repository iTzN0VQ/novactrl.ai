FAQ

What is a skill?

A skill is a set of instructions that teaches Claude to do one job the same way every time. It's a folder with a SKILL.md file in it, sometimes with scripts or reference files next to it.

When your request matches the job, Claude loads the skill and follows it step by step. Diamond System Intelligence, for example, teaches Claude to read a photo of the Field Survey Checklist, build the project in Diamond System Builder and export the submittal.

Skills run in Claude Code and in Cowork in the Claude desktop app.

How was Diamond System Intelligence built?

It's trained, not just written. Every day an agent on the latest Claude models works job after job in Diamond System Builder, and every roadblock and failure becomes something the skill knows the next time. It has also studied Mitsubishi's library of published manuals. The learning compounds, so the skill gets sharper the longer it trains. The full story

Is Diamond System Intelligence open source?

No. It's closed source. It's coming to Claude through a NovaCTRL connector here on novactrl.ai, and only NovaCTRL updates it, as it keeps training.
