FAQ

What is NovaCTRL?

NovaCTRL makes hardware, software and AI / SI skills for HVACR technicians, focused mainly on VRF technology: field devices, mobile tools for your phone and skills for Claude. Built for technicians, by technicians.

What is VRF?

VRF stands for variable refrigerant flow. One outdoor unit serves several indoor units, and an inverter compressor and electronic expansion valves vary how much refrigerant each zone gets. That's the equipment most of NovaCTRL's work is built around.

What is a skill?

A skill is a set of instructions that teaches Claude to do one job the same way every time. It's a folder with a SKILL.md file in it, sometimes with scripts or reference files next to it.

When your request matches the job, Claude loads the skill and follows it step by step. Diamond System Intelligence, for example, teaches Claude to read a photo of the Field Survey Checklist, build the project in Diamond System Builder and export the submittal.

Skills run in Claude Code and in Cowork in the Claude desktop app.

How was Diamond System Intelligence built?

It's trained, not just written. Every day an agent on the latest Claude models works job after job in Diamond System Builder, and every roadblock and failure becomes something the skill knows the next time. It has also studied Mitsubishi's library of published manuals. The learning compounds, so the skill gets sharper the longer it trains. The full story

What do I need to run Diamond System Intelligence?

Claude with the NovaCTRL connector, which is coming soon: the skill is closed source and reaches Claude through that connector. You'll also need a Windows machine with Diamond System Builder installed, where Claude has computer-use access to DSB and File Explorer. How it works

Do I need an account or an app for the mobile tools?

No. The mobile tools run in your phone's browser at novactrl.ai. There's nothing to sign up for and nothing to install.

Where do the PT chart numbers come from?

Every PT table is checked against a published manufacturer or NIST table, and the source is shown right on the page. The Sources page lists every table and the check that runs each time a tool loads.

Do the tools work without signal?

Yes, once a tool page has loaded. Everything it calculates runs on your phone, so it keeps working if you lose signal while it's open.

Does the site keep what I type?

Only your settings: your refrigerant, units and site elevation or barometer are saved in your own browser so they carry from one tool to the next. The readings you type aren't saved or sent anywhere, and the site has no ads, trackers or third-party scripts.

When can I get EEV Telemetry?

EEV Telemetry is in development and coming soon. It drives and ohms out Cam-type and Pam-type LEVs, 5-wire and 6-wire, and it will be in the Store Front when it's ready.
